# Checklist de test — Chilipir v0.1.0

## Instalare
- [ ] Installerul `.exe` pornește corect
- [ ] Installerul `.msi` pornește corect
- [ ] Aplicația se instalează fără erori
- [ ] Aplicația pornește după instalare

## Pornire aplicație
- [ ] Fereastra principală se deschide
- [ ] Dashboard-ul se încarcă
- [ ] Listele existente sunt vizibile
- [ ] Nu apar erori critice la pornire

## Watchlists
- [ ] O listă existentă se deschide corect
- [ ] Produsele sunt afișate corect în listă
- [ ] Se poate crea o listă nouă
- [ ] Se poate redenumi o listă
- [ ] Se poate șterge o listă

## Produse
- [ ] Se poate importa un produs din URL Freshful
- [ ] Titlul produsului este corect
- [ ] Imaginea produsului este corectă
- [ ] Categoria este afișată corect
- [ ] Package text este afișat corect

## Prețuri
- [ ] `latest_price_total` este afișat corect
- [ ] `latest_unit_price_value` este afișat corect
- [ ] `latest_unit_price_unit` este afișat corect
- [ ] Clasificarea Chilipir / Preț cinstit / Răsfăț este coerentă

## Refresh standard
- [ ] Butonul `Actualizează` funcționează
- [ ] Prețul se actualizează corect
- [ ] Prețul unitar se actualizează corect
- [ ] Availability se actualizează corect

## Refresh promo / rendered
- [ ] Butonul `Actualizează promo` funcționează
- [ ] Nu apare eroare `Not Found`
- [ ] Nu apare eroare `Promo engine indisponibil` când Chrome CDP este activ
- [ ] Refresh promo nu modifică greșit prețul final
- [ ] Refresh promo poate actualiza `discount_percent`
- [ ] Refresh promo poate actualiza metadatele promo fără să strice pricing-ul

## Promo bundle
- [ ] Produsele cu `promo_kind = bundle` păstrează prețul static corect
- [ ] `Actualizează promo` nu introduce preț greșit pentru bundle
- [ ] Badge-ul promo bundle este coerent

## Availability
- [ ] Produsele `in_stock` apar corect
- [ ] Produsele `out_of_stock` apar corect
- [ ] La `out_of_stock` nu mai apare badge promo greșit
- [ ] `Actualizează promo` nu resetează availability la `unknown` când static știe `out_of_stock`

## UI
- [ ] Dashboard-ul se încarcă fără layout broken
- [ ] Pagina listei se încarcă corect
- [ ] Cardurile produselor sunt lizibile
- [ ] Badge-urile sunt afișate corect
- [ ] Nu apar erori vizibile în consolă care blochează fluxul

## Închidere
- [ ] Aplicația se închide corect
- [ ] La repornire datele sunt încă disponibile
