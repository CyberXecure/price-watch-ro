# Chilipir v0.2.0-beta

Beta Windows desktop pentru price-watch-ro / Chilipir.

## Noutăți importante

- Refresh automat la deschiderea listei
- Buton „Actualizează acum”
- Chrome CDP pornit automat pentru promoții Freshful
- Chrome CDP izolat cu profil separat și extensii dezactivate
- Detectare smart pentru promoții de tip pachet
- Diferențiere între PROMO pachet și Pachet avantajos
- Deal scoring engine 0–100: Chilipir real / Bun / OK / Scump
- Ascundere old price și discount procentual pentru bundle-uri
- Navigare corectă între liste
- Installer Windows NSIS și MSI

## Limitări beta

- Momentan focus pe Freshful
- Aplicație local-first
- Datele și istoricul sunt locale
- Unele promoții Freshful pot necesita refresh rendered

## Instalare

Recomandat: descarcă și rulează installerul `.exe`.

Dacă Windows SmartScreen afișează avertisment, alege More info / Run anyway doar dacă ai descărcat installerul din acest release oficial.
